## Overview

Arturia DX7 V faithfully recreates the Yamaha DX7, the best-selling synthesizer of the 1980s, with its six-operator FM synthesis and expanded modern features beyond the original hardware.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Arturia DX7 V** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **6-Op FM** | Six-operator FM synthesis with 32 algorithm configurations |
| **1000+ Presets** | Classic DX7 factory banks plus modern sound design presets |
| **Modern Additions** | Unison, extra LFOs, and effects not available on the original |
| **DX7 Import** | Import original SysEx bank files from vintage DX7 units |
